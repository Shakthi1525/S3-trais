S3 Cube Solutions website (HTML, CSS, JavaScript)

Files:
- index.html                  Home page
- logistics-software.html     Logistics Software page
- training.html               Industry Training page
- support.html                Implementation & Support page
- css/styles.css              Shared responsive styles
- js/script.js                Mobile navigation, page selection, contact form feedback

How to run:
1. Extract this folder.
2. Open index.html in a browser, or use VS Code with the Live Server extension.
3. Keep the css and js folders in their current locations.

Notes:
- The design is recreated from the uploaded reference as a responsive, editable starter website.
- Hero photos are loaded from Unsplash URLs, so internet access is needed to show those photos.
- The contact form currently shows front-end confirmation only. Connect it to a backend or form service to receive real enquiries.
